# Geometrica: An Interactive Journey Through Mathematics

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Geometrica is a tool for visualising familiar tilings of the Euclidean plane to landscapes of hyperbolic and elliptic spaces.

---

## Development Philosophy & Current Status

To achieve this ambitious vision, "Geometrica" is being built in two distinct, deliberate acts. This phased approach ensures a solid foundation before moving on to more complex architectural and technical challenges.

> 🚧 **This project is currently in Act I: The Foundational Phase.**

The focus of this act is on mastering the core rendering logic and visualization algorithms using simple, direct technology (plain HTML, CSS, and JavaScript). This phase prioritizes rapid prototyping and a deep understanding of the fundamental graphics concepts that will underpin the entire application.

### How to Run This Project

As the project is in Act I, it does not yet require any build tools or installation steps.

1.  **Clone this repository** to your local machine:
    ```bash
    git clone https://github.com/your-username/geometrica.git
    ```

2.  **Navigate to the project directory**:
    ```bash
    cd geometrica
    ```

3.  **Open the main HTML file** directly in your web browser:
    *   Navigate to the `public/` folder.
    *   Open the `index.html` file.

## Architecture & Design Process

This project is being developed with a strong emphasis on upfront design and a transparent architectural process. The entire intellectual journey—from high-level whiteboarding to detailed feature design—is documented and version-controlled alongside the code in the `/docs` directory.

This directory is an [Obsidian](https://obsidian.md/) vault that serves as the project's "second brain" and contains:
*   **The Project Whiteboard:** The initial visual brainstorm and dependency map.
*   **The Development Roadmap:** The official "Learning Ladder" which sequences the project's features.
*   **Detailed Design Logs:** Formal design documents for every feature, created *before* the code is written, following a Progressive Formalization model inspired by C4.
*   **A Personal Wiki:** A growing knowledge base of all the technical concepts involved.

*(Please note: The documentation uses Obsidian's `[[WikiLink]]` format for interconnecting ideas, which may not be navigable directly on the GitHub website.)*
